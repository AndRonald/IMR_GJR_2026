Pergunta 1 (1 ponto)
 

Um robô móvel autônomo precisa se deslocar até um ponto de entrega em um ambiente parcialmente conhecido, onde obstáculos estáticos já constam no mapa, mas pessoas e carrinhos se movem de forma imprevisível. Qual arquitetura de navegação é mais adequada para esse cenário e por quê?
Opções da pergunta 1:
	

Arquitetura híbrida, combinando um planejador global (como A*) para traçar rotas livres de mínimos locais sobre o mapa estático e uma camada reativa local para desviar de obstáculos dinâmicos em tempo real.
	
	

Arquitetura puramente reativa baseada apenas em sensores de proximidade, pois mapas estáticos tornam o processamento lento e impedem o robô de contornar qualquer objeto em formato de U.
	
	

Planejamento global offline exclusivo, executando a lista de coordenadas gerada inicialmente sem consultar sensores durante o deslocamento, o que evita oscilações de trajetória.
	
	

Controle teleoperado assistido por odometria pura, dispensando sensores externos de distância desde que o motor possua controle preciso de aceleração e frenagem.

Pergunta 10 (1 ponto)
 

Analise atentamente o trecho de código abaixo, que representa o ciclo de atualização (passo_controle) de um robô autônomo móvel equipado com sensor frontal de distância e controle cinemático:

import math
from collections import deque

class ControladorAutonomo:
    def __init__(self):
        self.x = 0.0
        self.y = 0.0
        self.theta = 0.0          # Orientação em radianos
        self.v = 0.0              # Velocidade linear atual (m/s)
        self.a_freio = 4.0        # Desaceleração máxima (m/s²)
        self.janela_sensor = deque(maxlen=3)
        self.estado = "NAVEGANDO"

    def filtrar_leitura(self, leitura_bruta):
        self.janela_sensor.append(leitura_bruta)
        amostras_ordenadas = sorted(self.janela_sensor)
        return amostras_ordenadas[len(amostras_ordenadas) // 2]

    def passo_controle(self, leitura_bruta, angulo_alvo, dt):
        dist_segura = self.filtrar_leitura(leitura_bruta)
        dist_parada = (self.v ** 2) / (2.0 * self.a_freio)

        # Camada de Decisão Hierárquica (FSM)
        if dist_segura <= dist_parada + 0.30:
            self.estado = "FREIO_EMERGENCIA"
            v_desejada = 0.0
            w_desejada = 0.0
        elif dist_segura < 1.50:
            self.estado = "DESVIANDO"
            v_desejada = 0.8
            w_desejada = 1.2
        else:
            self.estado = "NAVEGANDO"
            v_desejada = 2.0
            erro_ang = (angulo_alvo - self.theta + math.pi) % (2 * math.pi) - math.pi
            w_desejada = max(-1.5, min(1.5, erro_ang * 2.5))

        # Atualização Cinemática
        self.v = v_desejada
        self.theta += w_desejada * dt
        self.x += self.v * math.cos(self.theta) * dt
        self.y += self.v * math.sin(self.theta) * dt
